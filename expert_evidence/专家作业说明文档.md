# ToB 242 专家作业说明

## 任务信息

- Task ID：`tob242_rcc8`
- 类型：S1 方法优化任务；任务配置已由本机 Harbor 0.23.0 静态加载，正式平台验收待运行
- 研究方向：图机器学习、关系推理、跨推理链长度泛化
- 本文件仅说明未来专家 Agent 研究的边界；本次没有启动 Agent 研究，也没有研究轨迹或结论

## Agent 将看到什么

Agent 只使用由 `workspace/harbor_task/environment/` 构建的公开镜像。题面是 `instruction.md`，起点是 `environment/starter/method.py` 中的 R-GCN，镜像内复制为 `/workspace/solution/method.py`。允许修改的唯一文件是该镜像内的 `method.py`。任务根 `solution/method.py` 是 Harbor Oracle 私有 Reference；常规 Agent 不接收它，也不接收出题方的 `workspace/reference/`、`expert_evidence/` 与训练证据。

任务采用作者原始 RCC-8 CSV 和原始 24 组测试题。原题公开，因此未来评分可以做执行隔离，但不能称测试题为从未公开的 Hidden。训练器负责分配训练标签，模型图输入不能含目标关系。

## 评分与复现约定

40 epoch、batch size 128、Adam learning rate 0.01、固定 seed 42、80/20 原始行划分及验证准确率选点规则见 `environment/public_assets/protocol.json`。Starter 使用宽度 32、9 轮传播；候选可研究其他结构，但受参数和时间限制。全部 24 组逐组报告准确率，k=5–9 的 15 组单列。AutoResearch score 使用实测 Baseline 锚点 B：`(A-B)/(1-B)`；当前 B、Reference 准确率和实际资源占用均未完成正式测定，不得自行补值。单 seed 无法计算样本标准差，不能证明改善超过训练随机波动；原教程的 `3σ_B` 质量门因此未满足，须由任务方明确接受该偏离。

Agent 的研究过程应保存真实时间、尝试的方法、运行命令、失败与成功结果、最终源码哈希及真实轨迹。最好候选需要独立从头复测；失败运行不能删去。没有运行时不创建轨迹、best method 或虚构消融结果。
